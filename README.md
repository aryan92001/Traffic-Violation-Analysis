## 📌 Project Overview

The **Gurgaon Traffic Violation Analysis** project focuses on analyzing traffic violations across different locations in Gurgaon, Haryana, using Microsoft Excel.

The project explores traffic violation patterns, identifies high-risk locations, evaluates fine collection and payment status, and examines how weather conditions influence traffic violations.

Using data cleaning, Pivot Tables, Pivot Charts, and analytical techniques, this project transforms raw traffic records into meaningful business insights that can support better traffic management and road safety decisions.

## 🎯 Project Objectives

- Analyze traffic violations across different locations in Gurgaon.
- Identify the most frequently reported traffic violations.
- Determine high-risk locations based on violation frequency.
- Evaluate fine amounts and revenue collection.
- Analyze paid, unpaid, and disputed fine payments.
- Examine the relationship between weather conditions and traffic violations.
- Compare different violation categories based on total and average fine amounts.
- Generate actionable insights to improve traffic management and road safety.

## 📂 Dataset Overview

The project contains **1,000 traffic violation records** covering the period from January 2024 to December 2024.

The dataset includes information about traffic violations, vehicles, drivers, locations, road conditions, weather, and fine payments.

### Key Dataset Columns

| Column | Description |
|---|---|
| Date | Date of traffic violation |
| Location | Location where violation occurred |
| Vehicle_Type | Type of vehicle involved |
| Violation_Type | Category of traffic violation |
| Fine Amount | Fine imposed on the offender |
| Repeat_Offender | Indicates whether the offender is a repeat offender |
| Weather_Condition | Weather during the violation |
| Time_of_Day | Time when violation occurred |
| Road_Condition | Condition of the road |
| Driver_Age_Group | Age category of the driver |
| Passengers_Count | Number of passengers |
| Traffic_Density | Traffic congestion level |
| License_Status | Driver's license status |
| Accident_Involved | Indicates accident involvement |
| Speed_Recorded (km/h) | Recorded vehicle speed |
| Vehicle_Registration_State | Vehicle registration state |
| Officer_ID | Traffic officer identification |
| Previous_Violations | Number of previous violations |
| Insurance_Penalty (₹) | Insurance-related penalty |
| Fine_Payment_Status | Paid, Unpaid, or Disputed |

## 📈 Key Analytical Findings

### 1. Location-Wise Traffic Violation Analysis

- Sikanderpur recorded the highest number of traffic violations, with **89 cases**.
- Sector 29 reported 74 violations.
- Cyber City, NH-8, and Sector 56 each recorded 71 violations.
- Signature Tower Chowk recorded the lowest number of violations, with 51 cases.

**Business Insight:** Sikanderpur requires greater traffic monitoring and enforcement attention because it recorded the highest violation frequency among the analyzed locations.

### 2. Violation Type Analysis

| Violation Type | Total Cases |
|---|---:|
| Wrong-Side Driving | 205 |
| Red-Light Jump | 192 |
| No Seatbelt | 191 |
| DUI | 175 |
| Speeding | 174 |
| No Helmet | 63 |

**Business Insight:** Wrong-side driving was the most frequently recorded violation, accounting for 20.5% of all cases. Enforcement strategies should prioritize wrong-side driving and traffic signal compliance.

### 3. Fine Collection & Revenue Analysis

- Total recorded fine amount: **₹37,17,899**
- Disputed fines: ₹12,61,635
- Paid fines: ₹12,57,695
- Unpaid fines: ₹11,98,569

**Business Insight:** Disputed fines represent the largest payment-status category by total fine amount. Improving the dispute-resolution process and payment follow-ups could help strengthen fine collection efficiency.

### 4. Weather-Wise Traffic Violation Analysis

| Weather Condition | Share of Violations |
|---|---:|
| Rainy | 22.9% |
| Cloudy | 20.3% |
| Foggy | 19.5% |
| Stormy | 19.5% |
| Clear | 17.8% |

**Business Insight:** Rainy weather recorded the highest overall share of violations at 22.9%. This highlights the importance of weather-aware traffic management and additional road safety measures during adverse weather.

### 5. Violation Type with Fine Amount Analysis

| Violation Type | Total Fine Amount |
|---|---:|
| DUI | ₹12,92,101 |
| Wrong-Side Driving | ₹10,05,081 |
| Red-Light Jump | ₹6,42,327 |
| Speeding | ₹5,09,451 |
| No Seatbelt | ₹2,03,626 |
| No Helmet | ₹65,313 |

**Business Insight:** DUI generated the highest fine amount, contributing approximately 34.8% of the total recorded fine amount. Wrong-side driving ranked second, contributing approximately 27.0%.
